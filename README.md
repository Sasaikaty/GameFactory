# WINT Game Factory v0.1

Phaser 3 + Vite starter for browser-first hypercasual games.

## Requirements
- Node.js LTS
- Git
- VS Code recommended

## Install

```bash
npm install
```

## Run

```bash
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
```

Production files are generated in `dist/`.

## Preview production build

```bash
npm run preview
```
